# jccash

Offline exchange budget tracker built for a semester abroad. No login, no ads, no API — everything lives on your device.

## Features

- Quick-add: amount, category, optional note, done in 2 taps
- Multi-currency: log in local currency, see SGD equivalent at a rate you set yourself
- Daily budget left: set a total budget and see how much you can spend per day for the rest of the trip
- Categories with a breakdown chart
- Split bills: track who owes you and tick it off when they pay
- Cash vs card tracking
- Trip tags to separate different trips
- CSV export
- Recurring costs (rent, phone plan auto-added monthly)
- Dark mode

## Development

Requires Node.js (or Bun).

```sh
git clone <repo-url>
cd jccash
bun install
bun run dev
```
