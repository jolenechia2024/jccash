# xchange budgeter

i want to build a cute user friendly budgeting calculator while i go for exchange 

Quick add: amount, category, optional note, and it's done in 2 taps. If logging is a hassle, you'll stop using it by week 2.

Multi-currency: log in the local currency and see the SGD equivalent. You set the exchange rate yourself (editable), so it works offline with no API or ads. 

Daily/weekly budget left: set a total budget for the exchange, and it shows "you can spend $X/day for the rest of the trip". This is probably the most useful feature.

Categories: food, transport, travel, rent, groceries, fun, etc. Add a simple breakdown chart.

Data saved on your device: no login, nothing uploaded.

Nice-to-haves

Split bills: for when you pay for the group dinner and friends owe you. Track who owes what and tick it off once they pay.

Cash vs card tracking: handy if you withdraw cash and want to know what's left.

Trip tags: separate "Europe backpacking" spending from daily life.

Export to CSV: for backup or Excel later.

Recurring costs: rent and phone plan auto-added each month.

Dark mode, because you'll be checking it at night in some hostel.
