# CLAUDE.md — jccash project instructions

## Ownership

This is a personal project. Do not add AI co-author credits, "Generated with Claude", "Built with Lovable", or any similar attribution anywhere — not in code, commits, comments, or docs.

## Before running builds or making it live

Always ask before:

- Running `bun run build`
- Pushing any branch
- Deploying or triggering any Netlify action
- Deleting files, branches, or any data

Do not push. Pushing is the user's job, always.

## Commits

Only commit when explicitly told to ("commit this", "commit now"). Do not make proactive commits, per-chunk commits, or "clean checkpoint" commits. Use one commit per related set of changes.

## Commands

```sh
bun run dev        # local dev server (Vite HMR)
bun run build      # production build → .output/
bun run preview    # preview the production build locally
bun run test       # run Vitest tests once
bun run test:watch # Vitest in watch mode
bun run lint       # ESLint
bun run format     # Prettier (writes files)
```

## Project context

See `structure.md` for the full architecture. Key points:

- All state is in `localStorage` via `src/lib/store.ts` — no backend, no API calls.
- The whole app UI is in one file: `src/routes/index.tsx`.
- `src/components/ui/` is shadcn/ui auto-generated code — do not edit by hand; add components with `bunx shadcn add <component>`.
- `src/routeTree.gen.ts` is auto-generated by the TanStack Router plugin — do not edit.
- Deployment target is Netlify. The app is accessed from a phone browser (no app store install).
